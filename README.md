# مولد جلسة Pyrogram V2 🇸🇦

أداة عربية بسيطة وآمنة لتوليد Session String لمكتبة Pyrogram الإصدار الثاني.

## ✨ المميزات

- ✅ **آمن بالكامل** - يعمل محلياً على جهازك
- ✅ **واجهة عربية** - سهلة الاستخدام للمستخدم العربي
- ✅ **لا يحفظ بيانات** - لا يخزن أي معلومات حساسة
- ✅ **يدعم Pyrogram V2** - أحدث إصدار
- ✅ **قائمة تفاعلية** - سهلة التنقل

## 📋 المتطلبات

- Python 3.7 أو أحدث
- حساب تليجرام نشط
- API ID و API Hash من [my.telegram.org](https://my.telegram.org)
